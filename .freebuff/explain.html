🏫 Radian O'quv Markazi CRM

Architecture, data flow, and role-based design of the education management system preview.

1. What This Is

A single-file HTML demo (preview.html, 705 lines) that simulates the Radian education center's CRM interface. It has a login page, 6 role-based dashboards, and sidebar navigation — all without a backend.

Key insight: This is a static prototype, not a running application. All data is hardcoded in JavaScript. The value is in validating the UX, role permissions, and information architecture before building the real NestJS + PostgreSQL system.

12. What's Next (Architecture Gap)

⚠️
Core limitation: All mock data is scattered across 22 render functions. A student named "Muhammad Ali" is independently defined in 8+ places. Changing one copy breaks consistency. A centralized DATA object would fix this and enable a smooth transition to real API calls.
💡
Topbar re-render: Every navigation click rebuilds the entire content area including the topbar. This loses search focus, scroll position, and form state. Splitting into renderTopbar() (once) and renderContent() (on nav) would fix this.
